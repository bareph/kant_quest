## 미니 프로젝트 발제 — 쇼핑몰 장바구니 & 할인 쿠폰

1. 프로젝트 개요

터미널에서 동작하는 **온라인 쇼핑몰 장바구니**를 만듭니다.상품을 둘러보고, 장바구니에 담고 빼고, **할인 쿠폰**을 골라 적용한 뒤 결제합니다. 결제하면 재고가 줄어듭니다.이번에는 **클래스 여러 개가 서로 협력**하는 프로그램입니다.

## 2. 학습 목표

| # | 목표 |
| --- | --- |
| 1 | 역할이 다른 클래스 여러 개를 설계할 수 있다 |
| 2 | 한 객체가 다른 객체를 속성으로 가지는 구조(조합)를 만들 수 있다 |
| 3 | 상속으로 공통 틀을 만들고, 자식 클래스에서 오버라이딩할 수 있다 |
| 4 | 같은 메서드 호출이 객체에 따라 다르게 동작하는 다형성을 설명할 수 있다 |
| 5 | 객체의 상태 변경을 메서드로만 하도록 캡슐화할 수 있다 |
| 6 | 클래스 변수로 객체에 자동 번호를 붙일 수 있다 |

## 3. 쇼핑몰 규칙

### 3-1. 판매 상품 (시작 데이터 예시)

- 초기 상품 목록은 자율

| 번호 | 상품명 | 가격 | 재고 |
| --- | --- | --- | --- |
| 1 | 무선 이어폰 | 89,000원 | 3 |
| 2 | 텀블러 | 15,000원 | 10 |
| 3 | 보조배터리 | 32,000원 | 5 |
| 4 | 마우스패드 | 9,000원 | 0 (품절) |
| 5 | USB 허브 | 18,000원 | 4 |
- 상품 번호는 직접 쓰지 않고 **객체를 만들 때 자동으로 1, 2, 3 … 부여**됩니다.

### 3-2. 메뉴

```
1.상품목록 2.담기 3.빼기 4.장바구니 5.쿠폰 6.결제 q.종료
```

| 메뉴 | 동작 |
| --- | --- |
| 1. 상품목록 | 전체 상품을 번호 · 가격 · 재고(또는 품절)로 출력 |
| 2. 담기 | 상품 번호와 수량을 받아 장바구니에 추가. 이미 담긴 상품이면 수량을 더함 |
| 3. 빼기 | 상품 번호를 받아 장바구니에서 제거 |
| 4. 장바구니 | 담긴 상품, 상품 합계, 할인, 배송비, 결제 금액 출력 |
| 5. 쿠폰 | 쿠폰 목록을 보여 주고 하나를 골라 적용 (한 번에 1장) |
| 6. 결제 | 영수증 출력 → 재고 감소 → 장바구니 비우기 → 쿠폰 초기화 |
| q | 프로그램 종료 |

### 3-3. 할인 쿠폰

| 쿠폰 | 클래스 | 할인 금액 계산 |
| --- | --- | --- |
| 쿠폰 없음 | Discount | 항상 0원 |
| 10% 할인 (최대 5,000원) | RateDiscount(rate=0.1, max_amount=5000) | 상품 합계 × 10%, 단 5,000원을 넘지 않음. 원 단위 미만은 버림 |
| 3,000원 할인 (20,000원 이상 구매 시) | FixedDiscount(amount=3000, min_total=20000) | 상품 합계가 20,000원 이상이면 3,000원, 아니면 0원 |

### 3-4. 결제 금액 계산 순서

```
① 상품 합계   = sum(가격 × 수량)
② 할인 금액   = 적용한 쿠폰.discount_amount(상품 합계)
③ 배송비      = (① - ②) 가 30,000원 이상이면 0원, 미만이면 3,000원  (장바구니가 비면 0원)
④ 결제 금액   = ① - ② + ③
```
